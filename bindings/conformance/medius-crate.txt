# every public thing of the medius crate anybox pins, and what C# and C++ have for it. the capi test that reads the
# crate's source fails on a row that's missing or left over, so a medius bump with something new stops check.sh
# until it's mapped here. the C# test finds each C# name by reflection, the C++ name has to be in anybox_medius.hpp,
# and every row held by the suite gets called by a scenario in medius.json
#
# a row is the Rust name | how it's held | the C# name | the C++ name | why, when it isn't just the same thing
#
# how it's held:
#   suite      medius.json replays it in both bindings against the crate
#   generated  gen-medius makes it from medius.h and checks it there
#   hand       each binding's own tests have it, it needs a thread, a wait or a callback
#   hardware   only a real box answers it, so it gets run on one before a release
#   language   the language does it, the note says how
#   upstream   medius-capi doesn't export it, so no binding can reach it yet, the docs say not exposed yet
#
# `Type::*` is every row of the type, `Type::CONSTANTS` every one of its uppercase constants
