# every public thing of the anybox crate, and what the C ABI, Python, C# and C++ have for it. the capi test that reads
# the crate's source fails on a row that's missing or left over, so something new in Rust stops check.sh until it's
# mapped here. the C name has to be in anybox.h, the Python and C# tests find theirs by name, and the C++ name has to
# be in anybox.hpp
#
# a row is the Rust name | the C name | the Python name | the C# name | the C++ name | why, when it isn't just the
# same thing
#
# the C name is a function, a constant (`ANYBOX_KEY_*` is a whole group of them), a type or a struct's field. an empty
# one is a value each binding builds itself, or something the language does, and the note says which.
# `Type::CONSTANTS` is every uppercase constant of the type, each binding's tests hold every one of them to the header
